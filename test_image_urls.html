🖼️ Image URL Tester

Paste any image URL from your ActivityStream component to test if it loads correctly.

📋 Paste an image URL above and click "Test Image" to check if it loads

🔍 Test Instructions:

  1. Open your ActivityStream component in the browser
  2. Open browser console (F12)
  3. Click the "🧪 Debug First Image URL" button
  4. Copy the image URL from the console
  5. Paste it in the input above and click "Test Image"

✅ Expected Results:

  • Working S3 URL: Image loads immediately
  • CORS Error: Image fails with CORS error (need crossOrigin="anonymous")
  • Access Denied: S3 URL expired or invalid permissions
  • Network Error: URL is malformed or server unreachable
