🔧 Troubleshooting:

            
If APIs redirect to /en/index/: The URL configuration needs to be fixed

            
If you get 404 errors: Make sure Django server is running on port 8000

            
If authentication fails: Update credentials in test scripts

            
Server not running? Run: python manage.py runserver
