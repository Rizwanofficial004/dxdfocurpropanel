Search Users

Get User Screenshots

GET /api/users/screenshots/?q=nawaz@dxdglobal.com&start_date=2025-10-01&end_date=2025-10-31

💡 Pro Tips:
  • Type just one letter (like 'n' or 'h') to see matching users
  • Click "Load All Users" to browse everyone
  • Use the calendar to filter by specific dates
  • Click any screenshot to open full size in a new tab
  • Check the console (F12) for detailed debugging info
⚠️ Troubleshooting:
  • No users found? Make sure your backend API is running on localhost:8000
  • Screenshots not loading? Check that the S3 proxy server is running on localhost:3001
  • 400 Bad Request? Verify date range is valid and API is accessible
  • Images not appearing? Check S3 bucket permissions and proxy configuration
